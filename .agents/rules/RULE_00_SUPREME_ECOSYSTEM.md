# RULE 00: 最上位絶対原則 ＆ エラー・報告厳格プロトコル (Supreme Ecosystem & Error Protocol)

本ドキュメントは、すべてのAIエージェントおよび開発スクリプトが遵守すべき**最上位の絶対遵守ルール**である。

---

## 1. 完了報告における「ユーザー指示達成度チェックリスト」義務化

1. **完了最優先による誤魔化しの排除**:
   - AIエージェントは、「タスク完了」のみを目的とし、ユーザーから指示された要件・引数・パラメータを無視・緩和・隠蔽して成功報告することを厳重に禁じる。
2. **【必須】完了報告チェックリストフォーマット**:
   完了報告時には、必ず以下の表形式でユーザー指示内容と検証結果を1対1で報告すること。

```markdown
### 📋 ユーザー指示履行確認チェックリスト
| 指示項目 / パラメータ | 指定値 / 要件 | 実際の実行・成果物検証値 | 合致判定 |
| :--- | :--- | :--- | :---: |
| サムネイル画像パス | `/path/to/thumb.jpg` | 物理ファイル存在確認済み (3840x2160) | ✅ 適合 |
| 動画総尺 | `60分00秒以上` | 3624.5秒 (60分24秒) | ✅ 適合 |
| 音声トラック | `WAV 24-bit 15曲` | 15ファイル完全ロード・マスタリング済み | ✅ 適合 |
| エラー・勝手な変更 | なし | 指示パラメータを100%厳守 | ✅ 適合 |
```

---

## 2. 想定外エラー発生時の行動規約（代替手段捏造・引数変更の絶対禁止）

1. **無断での代替手段捏造・引数変更の禁止**:
   - 実行時や開発中にエラーが発生した際、AIエージェントが独自に勝手な代替処理を捏造したり、引数・しきい値・制約を勝手に緩和して「成功」に見せかける行為を完全に禁止する。
2. **エラー発生時の正しいアクション**:
   - **ステップ1**: エラーログおよびスタックトレースを正確に取得する。
   - **ステップ2**: 以下のいずれかを選択する。
     - **ユーザーへの代替案提案**: 根本原因を説明し、対応可能な代替案を提示してユーザーの承認（y/n）を得てから実行する。
     - **安全な処理停止**: エラーを適切にキャッチして `sys.exit(1)` や例外を投げ、処理を途中で安全に停止する。
