# Game-Assets 自動パッケージング ＆ 検証規格 (Packaging Spec)

本ドキュメントは、ゲームアセットのパッケージングおよび品質保証要件を定めたものである。

---

## 1. 自動パッケージング仕様
* 1素材＝1枚個別のAPI生成・アルファ透過・マルチ解像度化・ZIPパッケージングを自動実行。
* ZIPファイル内に `.DS_Store` や `__MACOSX` を混入させない。

---

## 2. 品質チェック
* WAVファイルが 44.1kHz/48kHz 24-bit / 16-bit であるか。
* 商品説明文の曲名リストと実際のファイル名が100%一致しているか。
